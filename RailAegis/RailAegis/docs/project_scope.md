# Project Scope

## In scope (this repository)
- A local, web-based **simulation** of an inspection run with a simulated robot, sensors, obstacles and events.
- Operator controls, hazard warnings, event log, history, JSON export, automated tests, documentation.

## Out of scope / not done
- Any physical robot, electronics, firmware or mechanical design.
- Real sensor data, camera/vision processing, or detection of real track defects.
- Field testing of any kind, and any claim of accuracy or reliability.
- Safety certification or replacement of human railway inspection.

## Safety statement
This is a teaching and demonstration project. It does not assess real track condition. Real railway use would need
engineering, extensive validation, railway-authority approval and compliance with applicable safety standards.
Future hardware tests must use a safe, isolated test setup and never an operational railway track.
